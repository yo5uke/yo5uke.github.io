はじめに

本ページでは、私が開発した合成コントロール法（SCM）とその関連手法を統一インターフェースで提供するパッケージ、coresynthについて説明します。関数リファレンスや変更履歴など詳細はpkgdownのページも参考にしてください。

coresynthの最大の特徴はパフォーマンスです。計算上のボトルネックをすべてC++（RcppArmadillo）で実装しており、純Rの代替実装と比べてかなり高速化しています。

このパッケージでは、推定だけでなく可視化・推論・ロバストネス確認・JSON出力まで一連の分析フローを同じインターフェースで実行できます。たとえばConformal推論（conformal_inference()）を使えば、scm/sdid/gsc/mc/siのシャープフィットに対してp値と信頼区間を計算できます。

Noteご意見待ってます

実装・挙動に関するフィードバックや機能リクエストは、ページ下のコメントかGitHubのIssuesまでお寄せください。

このパッケージでできること

  • 6つの推定量（scm/sdid/gsc/mc/tasc/si）1をscm_fit()で統一的に推定
  • SharpだけでなくStaggered Adoption（およびSIではマルチアーム）にも対応
  • plot()でトレンド差・ギャップ・ウェイト、プラセボテストを共通フォーマットで可視化
  • 手法ごとの推論関数に加え、Conformal推論で仮定依存の小さい推論を実行
  • export_json()で結果をJSONに保存し、再現可能な分析フローを構築

coresynthが対応する推定量は以下の6つです。

推定量 method 参考文献
Synthetic Control Method "scm" Abadie et al. (2010)
Synthetic Difference-in-Differences "sdid" Arkhangelsky et al. (2021)
Generalised Synthetic Control "gsc" Xu (2017)
Matrix Completion "mc" Athey et al. (2021)
Time-Aware Synthetic Control "tasc" Rho et al. (2026)
Synthetic Interventions "si" Agarwal et al. (2024)

また、各推定量に対して複数の推論手法が利用できます。

推論手法 対応推定量 関数
プラセボテスト（Sharp） scm mspe_ratio_pval()
ランクに基づく置換検定（処置ユニットが複数） scm scm_rank_pval()
Jackknife / 重み付き乗数（Wild）Bootstrap（Staggered） scm scm_inference()
プラセボ / Bootstrap / Jackknife sdid sdid_inference()
残差Bootstrap（処置ユニットが少ない場合） gsc gsc_boot()
ユニットのBootstrap / Jackknife gsc gsc_inference()
ユニットのBootstrap / Jackknife si si_inference()
Conformal推論（CWZ 2021） scm, sdid, gsc, mc, si conformal_inference()

準備

パッケージを読み込みます。

library(coresynth)

本ページで使用するデータを生成します。47都道府県に相当するバランスパネル（ユニット数47、期間数30、真のATT = 2.5）を3因子モデルで生成します。

set.seed(2024)
N <- 47 # ユニット数（都道府県数相当）
TT <- 30 # 期間数（年）
T_pre <- 20 # 処置前期間
r <- 3 # 潜在因子数

# 3因子モデルによるパネル生成
F_t <- matrix(0, TT, r)
for (j in seq_len(r)) {
  F_t[, j] <- cumsum(rnorm(TT, 0, 0.4))
}
L_i <- matrix(abs(rnorm(N * r, 1, 0.3)), N, r)
Y <- L_i %*% t(F_t) + matrix(rnorm(N * TT, 0, 0.5), N, TT)

dat <- expand.grid(
  time = seq_len(TT),
  id = paste0("pref_", sprintf("%02d", seq_len(N)))
)
dat <- dat[order(dat$id, dat$time), ]

true_att <- 2.5
dat$y <- as.vector(t(Y))
dat$d <- as.integer(dat$id == "pref_01" & dat$time > T_pre)
dat$y[dat$d == 1] <- dat$y[dat$d == 1] + true_att # 真のATT = 2.5

idがユニット識別変数（pref_01〜pref_47）、timeが時間変数（1〜30）、yが結果変数、dが処置変数（処置ユニットpref_01が21期目以降に処置）です。ここでは先頭5行のみ表示しているのでdはすべて0になっています。pref_01以外の46ユニットがドナープールとなります。

scm_fit()

scm_fit()はすべての手法への統一エントリーポイントです。フォーミュラは 結果変数 ~ 処置変数 | ユニットID + 時間ID の形式で指定します。重要な点として、処置変数はあらかじめ作成が必要です。「処置ユニットかつ処置時点以降は1、それ以外は0」となるように処置変数を設定してください。

scm_fit(
  formula,
  data,
  method = c("scm", "sdid", "gsc", "mc", "tasc", "si"),
  ...,
  predictors = NULL,
  covariates = NULL,
  v_selection = c("insample", "oos"),
  donor_mspe_threshold = Inf,
  lambda_pen = NULL,
  v_optim = c("auto", "coord_descent", "bfgs", "multistart"),
  qp_solver = c("auto", "active_set", "wolfe"),
  v_window = NULL,
  nu = NULL,
  fixedeff = NULL,
  pool_cohorts = TRUE,
  weights = NULL
)
引数 説明
formula y ~ d | unit + time 形式のFormulaオブジェクト
data ロング形式のデータフレーム（1行 = 1ユニット×1時点）
method 推定手法の選択（"scm", "sdid", "gsc", "mc", "tasc", "si"）
predictors SCM用の予測変数リスト（pred()で指定）。NULLの場合は処置前アウトカムの各時点をそのまま予測変数として使用（期間平均ではない）
covariates 時変共変量の列名（"sdid", "gsc"、およびStaggeredな"scm"でサポート）。SharpなSCMでは受け付けず、predictorsで指定します
v_selection SCM用のV行列選択方法。"insample"（デフォルト）または Abadie (2021) の"oos"
donor_mspe_threshold ドナープール絞り込みの閾値（SCMのみ。デフォルトInfで無効）
lambda_pen ペナルティSCMのペナルティパラメータ（SCMのみ。NULLで通常SCM、"auto"で自動選択）
v_optim V外部最適化の手法（SCMのみ）。"auto"（デフォルト）は、予測変数を指定したフィットでは多出発点探索の"multistart"、処置前アウトカムのみを使うフィットでは"coord_descent"を選びます。"bfgs"は非推奨です
qp_solver 内側の二次計画問題のソルバー（SCMのみ）。"auto"（デフォルト）、"wolfe"、"active_set"
v_window V最適化で当てはまりを評価する処置前の時点（SharpなSCMのみ）。NULL（デフォルト）は処置前全期間
nu Staggered SCM用のPartial Pooling強度 (Ben-Michael et al. 2022)（SCM・Staggeredのみ）。デフォルトは"auto"（論文のヒューリスティックで自動選択）。[0, 1]の数値はコホート別不整合とプール不整合の凸結合を最小化（0でコホート別、1で完全プール）、"separate"はコホート別にV最適化する従来のパスです。donor_mspe_threshold・lambda_pen・v_selection = "oos"を指定すると"separate"になります
fixedeff 加法的な水準項。Staggered SCMでは各ユニットをコホート内の処置前平均で中心化してから推定します（デフォルトTRUE）。重み付きDIDに近い推定量になり、水準がユニット間で異なる場合にフィットが改善します。"mc"ではユニット・時点の固定効果をペナルティの外で推定します（デフォルトTRUE）
pool_cohorts Staggered SCMで、同じ時点に処置を受けたユニットを1つのブロックに平均してからウェイトを推定するか（デフォルトTRUE）。FALSEにするとユニットごとにウェイトを推定し、scm_rank_pval()で必要になります
weights SCMで、処置ユニットが集計ATTに占める重みを表す名前付きベクトル。NULL（デフォルト）は等ウェイトです

predictors = NULL は「処置前を1期ずつ合わせる」設定です。処置前全期間の平均で合わせたい場合は、pred(..., op = "mean") を明示的に指定します。

すべての手法は c("coresynth_<method>", "coresynth") クラスのオブジェクトを返します。共通フィールドは以下の通りです。

  • method：推定量名
  • estimate：ATT推定値
  • times：時間インデックスベクトル
  • T_pre：処置前期間数
  • Y_treat：処置ユニットの結果系列
  • gap：処置効果系列（\(Y_{\text{treat}} - Y_{\text{synthetic}}\)）

予測変数の指定（pred()）

SCMは pred() 関数を使って Abadie et al. (2010) §2.3の予測変数行列を指定できます。よくあるのは、処置前の結果変数を期間平均で使う方法だと思いますので、基本的にはpredを指定することになると思います。

# dat に income, unemp 列がある想定の例
fit_scm_cov <- scm_fit(
  y ~ d | id + time,
  data   = dat,
  method = "scm",
  predictors = list(
    pred(c("income", "unemp"), 1:8),     # 1〜8期平均
    pred("y", 5),                         # 5期の結果変数
    pred("y", 1:4, op = "mean")           # 1〜4期の平均
  )
)

pred() の op 引数には "mean"（デフォルト）、"median"、"sum" が指定できます。

処置前全期間の平均を1つのpredictorとして使いたい場合は、次のように書けます。

fit_scm_mean <- scm_fit(
  y ~ d | id + time,
  data = dat,
  method = "scm",
  predictors = list(
    pred("y", 1:T_pre, op = "mean")
  )
)

因子数rは、指定しなければ Xu (2017) のAlgorithm 1に従い、処置前期間の1期除外クロスバリデーションで選ばれます。加法的な固定効果はforce（"none"、"unit"、"time"、"two-way"）で加えられます。

GSCは時変共変量の調整を covariates 引数でサポートしています（dataの列名を文字ベクトルで指定）。内部では、対照ユニットから Bai (2009) の反復（特異値分解による因子の抽出と、共変量の係数の推定を交互に実行）で因子と係数を推定します。

Staggered Adoption

6つの手法すべてがStaggered Adoptionに対応していますが、内部の扱いは2通りに分かれます。

  • scm / sdid / gsc / si：各コホートを個別に推定し、\(N_{\text{treated}} \times T_{\text{post}}\) に比例したウェイトでATTを集計するアプローチ (Clarke et al. 2024) を採用しています。結果には$cohort_estimatesフィールドが追加され、control_group引数でドナープールを制御できます。
  • mc / tasc：コホート分割は行わず、各処置ユニット固有の処置開始時点以降を欠測値として扱う補完ベースの手法でStaggered Adoptionに対応します。ATTは処置ユニットごとの事後平均ギャップの単純平均です。$cohort_estimatesやcontrol_groupはサポートされません。
# pref_01: 21期から処置、pref_02: 26期から処置
dat_s <- dat
dat_s$d <- 0L
dat_s$d[dat_s$id == "pref_01" & dat_s$time > 20] <- 1L
dat_s$d[dat_s$id == "pref_02" & dat_s$time > 25] <- 1L
dat_s$y[dat_s$d == 1] <- dat_s$y[dat_s$d == 1] + 2.5

fit_sdid_s <- scm_fit(y ~ d | id + time, data = dat_s, method = "sdid")
print(fit_sdid_s)
=== coresynth fit ===
Method : SDID (staggered)
Estimate (ATT): 4.2508 
Cohorts: 2

コホート別の推定値は $cohort_estimates フィールドで確認できます（scm/sdid/gsc/siのみ）。

1     21         1    20     10 4.995919 0.6666667
2     26         1    25      5 2.760583 0.3333333

control_group 引数でドナープールを制御できます（scm/sdid/gsc/siのみ）。

  • "never_treated"（デフォルト）：never-treatedのみをドナーとして使用 (Clarke et al. 2024)
  • "clean"（非推奨）：never-treated + future adoptersをドナーとして使用。future adoptersの処置後の値が反事実の推定に混入するため、非推奨です
fit_sdid_never <- scm_fit(
  y ~ d | id + time,
  data          = dat_s,
  method        = "sdid",
  control_group = "never_treated"
)

SCMのPartial PoolingとFixed Effects（nu, fixedeff）

Staggered SCM（method = "scm"）は、nu引数でコホート間の情報をプールします (Ben-Michael et al. 2022)。nuは[0, 1]の数値（0＝コホートごとに別々、1＝完全プール）か、デフォルトの"auto"（論文のヒューリスティックで自動選択）を指定します。"separate"を指定すると、コホート別にV最適化する従来のパスで推定します。fixedeff（Staggered SCMではデフォルトでTRUE）は、各ユニットをコホート内の処置前平均で中心化してから推定するもので、水準差を吸収する重み付きDIDに近い推定量になります。

fit_scm_pooled <- scm_fit(
  y ~ d | id + time,
  data = dat_s,
  method = "scm",
  nu = "auto",
  fixedeff = TRUE
)
fit_scm_pooled$estimate
[1] 4.302017
fit_scm_pooled$pooling$nu
[1] 0.7854876

バランス診断（コホート別/プールそれぞれの不整合q_sep・q_poolなど）は$poolingフィールドに保存されます。

Staggered SCM専用の推論関数としてscm_inference()も用意されています。詳しくは推論の節を参照してください。

plot()

plot() で4種類のプロットを出力できます。

plot(fit, type = c("trend", "gap", "weights", "pred_weights"))
  • "trend"：処置ユニット vs. 合成コントロールの時系列
  • "gap"：処置効果の時系列（\(Y_{\text{treated}} - Y_{\text{synthetic}}\)）
  • "weights"：ドナーユニットのウェイト棒グラフ（SCM・SDID・SI）

推論

各推定量に対応した推論関数が用意されています。

どの推論を使うか

  • SCM（Sharp）でドナー単位のプラセボ比較を行いたい：mspe_ratio_pval()
  • SCMで処置ユニットが複数ある場合にランクに基づく置換検定を使いたい：scm_rank_pval()
  • SCM（Staggered）でJackknifeまたはWild Bootstrap推論を使いたい：scm_inference()
  • SDIDで標準的な推論（placebo / bootstrap / jackknife）を使いたい：sdid_inference()
  • GSCで処置ユニットが少ない場合に、因子モデルの残差をリサンプリングする推論を使いたい：gsc_boot()
  • GSC/SIで処置ユニットをリサンプリングする推論（処置ユニットが2つ以上必要）を使いたい：gsc_inference(), si_inference()
  • scm/sdid/gsc/mc/siのシャープフィットで置換ベースの区間推論を使いたい：conformal_inference()

SCM：プラセボテスト（mspe_ratio_pval()）

Abadie et al. (2010) / Abadie (2021) のMSPE比率に基づく置換検定です。各ドナーを処置ユニットとして扱ったプラセボSCMを推定します。Staggered SCMフィットには対応していません（後述のscm_inference()を使ってください）。

合成コントロール法の実行結果に対して、mspe_ratio_pval()を呼び出すと、プラセボ分布に基づくp値が返ります。

inf_scm <- mspe_ratio_pval(fit_scm)
inf_scm$p_value
[1] 0.0212766
mspe_ratio_pval(
  fit,
  mspe_threshold = 0,     # プラセボに含める最小MSPE（デフォルト：0）
  max_iter       = 100L,
  tol            = 1e-4,
  use_covariates = NULL,  # NULL（デフォルト）は処置フィットの予測変数指定をプラセボにも適用
  alternative    = c("two.sided", "greater", "less"),
  mspe_prune     = Inf,   # 処置前MSPEが処置ユニットの何倍を超えるプラセボを除外するか
  statistic      = c("ratio", "post_mspe")
)

mspe_pruneは、処置前のMSPEが処置ユニットの指定倍数を超えるプラセボを分布から除きます。Abadie et al. (2010) は20倍・5倍・2倍を用いています。statisticは順位をつける統計量で、"ratio"（デフォルト）は処置後/処置前のMSPE比、"post_mspe"は処置後MSPEそのもの（有限のmspe_pruneと併用）です。

use_covariatesはNULLがデフォルトです。predictorsを指定したSCMフィットに対しては、各プラセボユニットも同じ予測変数指定で再推定されます（Abadie et al. 2010 / Synthの慣例：処置ユニットとプラセボの検定統計量を共通の仕様で計算）。outcomes-onlyのフィットでは高速なC++実装のプラセボループが使われ、挙動は変わりません。TRUE/FALSEで明示的にどちらかのパスを強制することもできますが、FALSEを共変量フィットに使うと、共変量ベースの処置統計量とoutcomes-onlyのプラセボ統計量を比較することになり、置換検定の交換可能性が崩れる点に注意してください。

プロットは以下のコマンドから実行できます。

plot(inf_scm, type = "gaps")

SCM（Staggered）：Jackknife・Wild Bootstrap推論（scm_inference()）

Staggered SCMフィット専用の推論関数で、Ben-Michael et al. (2022) の2つの手法を提供します。method = "jackknife"（デフォルト）は付録A.1のleave-one-unit-outで、処置ユニットもドナーも1つずつ除外してウェイトを推定し直し、集計ATTを再計算します。method = "wild_bootstrap"は§5.3の重み付き乗数（wild）ブートストラップで、ウェイトは固定したまま各ユニットの寄与にゴールデン比の2値乗数（平均0・分散1）を掛けて再標本化します。再推定が不要なので、ユニット数が多いパネルではこちらが現実的です。Sharpフィットには使えません（mspe_ratio_pval()またはconformal_inference()を使ってください）。

inf_scm_s <- scm_inference(
  fit_scm_pooled,
  method = "wild_bootstrap",
  n_boot = 200,
  seed = 42
)
inf_scm_s$p_value
[1] 0.004975124
inf_scm_s$ci_lower
[1] 2.225541
inf_scm_s$ci_upper
[1] 6.276745
scm_inference(
  fit,
  method      = c("jackknife", "wild_bootstrap"),
  n_boot      = 1000L,
  level       = 0.95,
  alternative = c("two.sided", "greater", "less"),
  seed        = NULL
)

Partial Pooling（nu）・Fixed Effects（fixedeff）どちらのパスにも対応しており、コホート集計ウェイト（\(N_{\text{treated}} \times T_{\text{post}}\)）も考慮されます。処置ユニット数が少ないと推論の信頼性が下がるため、処置ユニットが3つ未満の場合は警告が出ます。

SDID：sdid_inference()

Clarke et al. (2024) に基づく3種類の推論手法を提供します。

# プラセボ検定（デフォルト）。SE・CIも自動で付与される
inf_sdid <- sdid_inference(fit_sdid, method = "placebo")
inf_sdid$p_value
[1] 0.0212766
inf_sdid$se
[1] 0.3462874
inf_sdid$ci_lower
[1] 1.847862
inf_sdid$ci_upper
[1] 3.205284

プラセボ検定では、処置ユニットを除いたうえで各ドナーを順に処置ユニットとみなし、ウェイトを含む推定量全体を再推定してプラセボ分布を作ります（処置ユニットが複数の場合はn_boot回のランダムな割り当て）。p値はプラセボ分布に基づく置換p値ですが、SEはプラセボ分布の分散 (Clarke et al. 2024 Algorithm 4)、CIはその正規近似です。処置ユニットのノイズがドナーと同程度であることを仮定しているため、ドナープールが小さい場合は解釈に注意してください。また、処置ユニット数よりドナー数が多い必要があります。

ブートストラップとジャックナイフは、処置ユニットも含めてユニットをリサンプリング（ジャックナイフは1ユニットずつ除外）するため、処置ユニットが2つ以上必要です（1つの場合はエラーになり、method = "placebo"を案内されます）。ここでは処置ユニットが2つあるStaggeredのフィット（fit_sdid_s）を使います。ブートストラップは処置・対照を区別せずパネル全体から復元抽出し、そのたびにウェイトも含めて推定し直します (Clarke et al. 2024 Algorithm 2)。

# ブートストラップ（SE・CI付き）
inf_sdid_boot <- sdid_inference(
  fit_sdid_s,
  method = "bootstrap",
  n_boot = 200,
  seed = 42
)
inf_sdid_boot$se
[1] 0.8679216
inf_sdid_boot$ci_lower
[1] 2.635907
inf_sdid_boot$ci_upper
[1] 5.269066
sdid_inference(
  fit,
  method      = c("placebo", "bootstrap", "jackknife", "jackknife_global"),
  n_boot      = 200L,   # bootstrap のみ
  level       = 0.95,
  alternative = c("two.sided", "greater", "less"),
  seed        = NULL
)

GSC：gsc_boot()

Xu (2017) のAlgorithm 2に基づく、推定された因子モデルの残差をリサンプリングするBootstrapです（処置効果のないパネルを推定値から作り直して再推定します）。残差は系列ごとリサンプリングして系列相関を保ち、対照ユニットには標本内残差、処置ユニットには対照ユニットを1つ処置ユニットとみなして除外した予測誤差を使います。リサンプリングできる処置ユニットが少ない場合に論文が推奨する方法で、処置ユニットが1つでも使えます。信頼区間は、推定値からBootstrap分布の分位点を引いて求めます。

inf_gsc <- gsc_boot(fit_gsc, B = 499, seed = 42)
inf_gsc$p_value
[1] 0.002
inf_gsc$ci_lower
[1] 1.808407
inf_gsc$ci_upper
[1] 4.939201
gsc_boot(
  fit,
  B     = 499L,
  alpha = 0.05,
  seed  = NULL
)

GSC：gsc_inference()

処置ユニットと対照ユニットを別々にリサンプリングして推定し直すBootstrap、または1ユニットずつ除外するJackknifeです。SharpフィットにもStaggeredフィットにも使えます。処置ユニットをリサンプリングするため、処置ユニットが2つ以上必要です（1つの場合はgsc_boot()かconformal_inference()を使ってください）。Staggeredフィットでmethod = "jackknife"を使うには、各コホートに処置ユニットが2つ以上必要です。method = "jackknife_global"は、パネル全体から1ユニットずつ除外してコホート間の共分散を保ちます。

gsc_inference(
  fit,
  method      = c("bootstrap", "jackknife", "jackknife_global"),
  n_boot      = 499L,
  level       = 0.95,
  alternative = c("two.sided", "greater", "less"),
  seed        = NULL
)

SI：si_inference()

Agarwal et al. (2024) に対して、gsc_inference()と同じ方式のユニットのBootstrap / Jackknife推論を提供します。Staggeredフィットにも対応しています。処置ユニットも含めてリサンプリングするため、処置ユニットが2つ以上必要です（1つの場合はエラーになります）。ここでは処置ユニットが2つあるdat_sで推定し直します。

fit_si_s <- scm_fit(y ~ d | id + time, data = dat_s, method = "si")
inf_si <- si_inference(fit_si_s, method = "bootstrap", n_boot = 499, seed = 42)
inf_si$p_value
[1] 1.142179e-07
si_inference(
  fit,
  method      = c("bootstrap", "jackknife", "jackknife_global"),
  n_boot      = 499L,
  level       = 0.95,
  alternative = c("two.sided", "greater", "less"),
  seed        = NULL
)

Conformal推論：conformal_inference()

Chernozhukov et al. (2021) の手法です。Moving-Block置換を用いた置換p値と信頼区間を返します。scm/sdid/gsc/mc/siのシャープフィットに対応しています。

inf_conf <- conformal_inference(fit_scm, level = 0.95)
inf_conf$p_value
[1] 0.03333333
inf_conf$ci_lower
[1] 1.211646
inf_conf$ci_upper
[1] 7.618931
# SDIDでも同様に使える
inf_conf_sdid <- conformal_inference(fit_sdid, level = 0.95)
inf_conf_sdid$p_value
[1] 0.06666667
conformal_inference(
  fit,
  tau0        = 0,    # 帰無仮説のATT（デフォルト：0）
  q           = 1,    # S_q統計量の指数（デフォルト：1）
  alternative = c("two.sided", "greater", "less"),
  ci          = TRUE,
  level       = 0.95,
  grid        = NULL,     # 候補値ベクトル（NULLの場合は自動設定）
  n_grid      = 200L,
  grid_mult   = 4
)
引数 説明
fit scm_fit()の結果（scm/sdid/gsc/mc/si、シャープフィット）
tau0 報告するp値の帰無ATT（デフォルト：0）
q \(S_q = (T_{\text{post}}^{-1}\sum\lvert u_t\rvert^q)^{1/q}\) の指数。alternative = "two.sided"のときのみ使われ、片側検定では処置後残差の符号付き平均を使う
alternative 対立仮説の方向
ci 信頼区間を構築するか（デフォルト：TRUE）
level 信頼水準（デフォルト：0.95）
grid 検定反転の候補\(\tau_0\)ベクトル。そのまま使われる。NULLの場合は推定値を中心に自動設定し、区間がグリッドの端に達する間は外側に広げる
n_grid 初期グリッドの点数（デフォルト：200）
grid_mult 初期グリッド半幅の乗数（処置前残差の標準偏差の何倍か。デフォルト：4）

## はじめに

本ページでは、私が開発した合成コントロール法（SCM）とその関連手法を統一インターフェースで提供するパッケージ、`coresynth`について説明します。関数リファレンスや変更履歴など詳細は[pkgdownのページ](https://yo5uke.com/coresynth/)も参考にしてください。

`coresynth`の最大の特徴は**パフォーマンス**です。計算上のボトルネックをすべてC++（RcppArmadillo）で実装しており、純Rの代替実装と比べて**かなり高速化**しています。

このパッケージでは、推定だけでなく**可視化・推論・ロバストネス確認・JSON出力**まで一連の分析フローを同じインターフェースで実行できます。たとえばConformal推論（`conformal_inference()`）を使えば、`scm`/`sdid`/`gsc`/`mc`/`si`のシャープフィットに対してp値と信頼区間を計算できます。

## このパッケージでできること

- 6つの推定量（`scm`/`sdid`/`gsc`/`mc`/`tasc`/`si`）^[合成コントロール法（Synthetic Control Method）、合成差の差法（Synthetic Difference-in-Differences）、一般化合成コントロール法（Generalised Synthetic Control）、行列補完法（Matrix Completion）、時間考慮型合成コントロール（Time-Aware Synthetic Control）、合成介入法（Synthetic Interventions）]を`scm_fit()`で統一的に推定
- SharpだけでなくStaggered Adoption（およびSIではマルチアーム）にも対応
- `plot()`でトレンド差・ギャップ・ウェイト、プラセボテストを共通フォーマットで可視化
- 手法ごとの推論関数に加え、Conformal推論で仮定依存の小さい推論を実行
- `export_json()`で結果をJSONに保存し、再現可能な分析フローを構築

`coresynth`が対応する推定量は以下の6つです。

| 推定量 | `method` | 参考文献 |
|:-------|:---------|:---------|
| Synthetic Control Method | `"scm"` | @abadie_synthetic_2010 |
| Synthetic Difference-in-Differences | `"sdid"` | @arkhangelsky_synthetic_2021 |
| Generalised Synthetic Control | `"gsc"` | @xu_generalized_2017 |
| Matrix Completion | `"mc"` | @athey_matrix_2021 |
| Time-Aware Synthetic Control | `"tasc"` | @rho_time-aware_2026 |
| Synthetic Interventions | `"si"` | @agarwal_synthetic_interventions_2024 |

また、各推定量に対して複数の推論手法が利用できます。

| 推論手法 | 対応推定量 | 関数 |
|:---------|:-----------|:-----|
| プラセボテスト（Sharp） | `scm` | `mspe_ratio_pval()` |

| ユニットのBootstrap / Jackknife | `gsc` | `gsc_inference()` |
| ユニットのBootstrap / Jackknife | `si` | `si_inference()` |
| Conformal推論（CWZ 2021） | `scm`, `sdid`, `gsc`, `mc`, `si` | `conformal_inference()` |

for (j in seq_len(r)) {
  F_t[, j] <- cumsum(rnorm(TT, 0, 0.4))
}
L_i <- matrix(abs(rnorm(N * r, 1, 0.3)), N, r)
Y <- L_i %*% t(F_t) + matrix(rnorm(N * TT, 0, 0.5), N, TT)

dat$y <- as.vector(t(Y))

dat$y[dat$d == 1] <- dat$y[dat$d == 1] + true_att # 真のATT = 2.5

## `scm_fit()`

`scm_fit()`はすべての手法への統一エントリーポイントです。フォーミュラは `結果変数 ~ 処置変数 | ユニットID + 時間ID` の形式で指定します。重要な点として、処置変数はあらかじめ作成が必要です。「**処置ユニットかつ処置時点以降は1、それ以外は0**」となるように処置変数を設定してください。

``` r
scm_fit(
  formula,
  data,
  method = c("scm", "sdid", "gsc", "mc", "tasc", "si"),
  ...,
  predictors = NULL,
  covariates = NULL,
  v_selection = c("insample", "oos"),
  donor_mspe_threshold = Inf,
  lambda_pen = NULL,
  v_optim = c("auto", "coord_descent", "bfgs", "multistart"),
  qp_solver = c("auto", "active_set", "wolfe"),
  v_window = NULL,
  nu = NULL,
  fixedeff = NULL,
  pool_cohorts = TRUE,
  weights = NULL
)
```

| 引数 | 説明 |
|:-----|:-----|
| `formula` | `y ~ d | unit + time` 形式のFormulaオブジェクト |
| `data` | ロング形式のデータフレーム（1行 = 1ユニット×1時点） |
| `method` | 推定手法の選択（`"scm"`, `"sdid"`, `"gsc"`, `"mc"`, `"tasc"`, `"si"`） |
| `predictors` | SCM用の予測変数リスト（`pred()`で指定）。`NULL`の場合は処置前アウトカムの**各時点**をそのまま予測変数として使用（期間平均ではない） |
| `covariates` | 時変共変量の列名（`"sdid"`, `"gsc"`、およびStaggeredな`"scm"`でサポート）。SharpなSCMでは受け付けず、`predictors`で指定します |
| `v_selection` | SCM用のV行列選択方法。`"insample"`（デフォルト）または @abadie_using_2021 の`"oos"` |
| `donor_mspe_threshold` | ドナープール絞り込みの閾値（SCMのみ。デフォルト`Inf`で無効） |
| `lambda_pen` | ペナルティSCMのペナルティパラメータ（SCMのみ。`NULL`で通常SCM、`"auto"`で自動選択） |
| `v_optim` | V外部最適化の手法（SCMのみ）。`"auto"`（デフォルト）は、予測変数を指定したフィットでは多出発点探索の`"multistart"`、処置前アウトカムのみを使うフィットでは`"coord_descent"`を選びます。`"bfgs"`は非推奨です |
| `qp_solver` | 内側の二次計画問題のソルバー（SCMのみ）。`"auto"`（デフォルト）、`"wolfe"`、`"active_set"` |
| `v_window` | V最適化で当てはまりを評価する処置前の時点（SharpなSCMのみ）。`NULL`（デフォルト）は処置前全期間 |
| `nu` | Staggered SCM用のPartial Pooling強度 [@ben-michael_synthetic_2022]（SCM・Staggeredのみ）。デフォルトは`"auto"`（論文のヒューリスティックで自動選択）。`[0, 1]`の数値はコホート別不整合とプール不整合の凸結合を最小化（`0`でコホート別、`1`で完全プール）、`"separate"`はコホート別にV最適化する従来のパスです。`donor_mspe_threshold`・`lambda_pen`・`v_selection = "oos"`を指定すると`"separate"`になります |
| `fixedeff` | 加法的な水準項。Staggered SCMでは各ユニットをコホート内の処置前平均で中心化してから推定します（デフォルト`TRUE`）。重み付きDIDに近い推定量になり、水準がユニット間で異なる場合にフィットが改善します。`"mc"`ではユニット・時点の固定効果をペナルティの外で推定します（デフォルト`TRUE`） |
| `pool_cohorts` | Staggered SCMで、同じ時点に処置を受けたユニットを1つのブロックに平均してからウェイトを推定するか（デフォルト`TRUE`）。`FALSE`にするとユニットごとにウェイトを推定し、`scm_rank_pval()`で必要になります |
| `weights` | SCMで、処置ユニットが集計ATTに占める重みを表す名前付きベクトル。`NULL`（デフォルト）は等ウェイトです |
: {tbl-colwidths="[25,75]"}

`predictors = NULL` は「処置前を1期ずつ合わせる」設定です。処置前全期間の平均で合わせたい場合は、`pred(..., op = "mean")` を明示的に指定します。

すべての手法は `c("coresynth_<method>", "coresynth")` クラスのオブジェクトを返します。共通フィールドは以下の通りです。

- `method`：推定量名
- `estimate`：ATT推定値
- `times`：時間インデックスベクトル
- `T_pre`：処置前期間数
- `Y_treat`：処置ユニットの結果系列
- `gap`：処置効果系列（$Y_{\text{treat}} - Y_{\text{synthetic}}$）

#### 予測変数の指定（`pred()`）

SCMは `pred()` 関数を使って @abadie_synthetic_2010 §2.3の予測変数行列を指定できます。よくあるのは、処置前の結果変数を期間平均で使う方法だと思いますので、基本的には`pred`を指定することになると思います。

``` r
# dat に income, unemp 列がある想定の例
fit_scm_cov <- scm_fit(
  y ~ d | id + time,
  data   = dat,
  method = "scm",
  predictors = list(
    pred(c("income", "unemp"), 1:8),     # 1〜8期平均
    pred("y", 5),                         # 5期の結果変数
    pred("y", 1:4, op = "mean")           # 1〜4期の平均
  )
)
```

`pred()` の `op` 引数には `"mean"`（デフォルト）、`"median"`、`"sum"` が指定できます。

処置前全期間の平均を1つのpredictorとして使いたい場合は、次のように書けます。

``` r
fit_scm_mean <- scm_fit(
  y ~ d | id + time,
  data = dat,
  method = "scm",
  predictors = list(
    pred("y", 1:T_pre, op = "mean")
  )
)
```

## Staggered Adoption

6つの手法すべてがStaggered Adoptionに対応していますが、内部の扱いは2通りに分かれます。

- `scm` / `sdid` / `gsc` / `si`：各コホートを個別に推定し、$N_{\text{treated}} \times T_{\text{post}}$ に比例したウェイトでATTを集計するアプローチ [@clarke_synthetic_2024] を採用しています。結果には`$cohort_estimates`フィールドが追加され、`control_group`引数でドナープールを制御できます。
- `mc` / `tasc`：コホート分割は行わず、各処置ユニット固有の処置開始時点以降を欠測値として扱う補完ベースの手法でStaggered Adoptionに対応します。ATTは処置ユニットごとの事後平均ギャップの単純平均です。`$cohort_estimates`や`control_group`はサポートされません。

```{r}
# pref_01: 21期から処置、pref_02: 26期から処置
dat_s <- dat
dat_s$d <- 0L
dat_s$d[dat_s$id == "pref_01" & dat_s$time > 20] <- 1L
dat_s$d[dat_s$id == "pref_02" & dat_s$time > 25] <- 1L
dat_s$y[dat_s$d == 1] <- dat_s$y[dat_s$d == 1] + 2.5

fit_sdid_s <- scm_fit(y ~ d | id + time, data = dat_s, method = "sdid")
print(fit_sdid_s)
```

コホート別の推定値は `$cohort_estimates` フィールドで確認できます（`scm`/`sdid`/`gsc`/`si`のみ）。

```{r}
fit_sdid_s$cohort_estimates
```

`control_group` 引数でドナープールを制御できます（`scm`/`sdid`/`gsc`/`si`のみ）。

- `"never_treated"`（デフォルト）：never-treatedのみをドナーとして使用 [@clarke_synthetic_2024]
- `"clean"`（非推奨）：never-treated + future adoptersをドナーとして使用。future adoptersの処置後の値が反事実の推定に混入するため、非推奨です

``` r
fit_sdid_never <- scm_fit(
  y ~ d | id + time,
  data          = dat_s,
  method        = "sdid",
  control_group = "never_treated"
)
```

### SCMのPartial PoolingとFixed Effects（`nu`, `fixedeff`）

Staggered SCM（`method = "scm"`）は、`nu`引数でコホート間の情報をプールします [@ben-michael_synthetic_2022]。`nu`は`[0, 1]`の数値（`0`＝コホートごとに別々、`1`＝完全プール）か、デフォルトの`"auto"`（論文のヒューリスティックで自動選択）を指定します。`"separate"`を指定すると、コホート別にV最適化する従来のパスで推定します。`fixedeff`（Staggered SCMではデフォルトで`TRUE`）は、各ユニットをコホート内の処置前平均で中心化してから推定するもので、水準差を吸収する重み付きDIDに近い推定量になります。

```{r}
fit_scm_pooled <- scm_fit(
  y ~ d | id + time,
  data = dat_s,
  method = "scm",
  nu = "auto",
  fixedeff = TRUE
)
fit_scm_pooled$estimate
fit_scm_pooled$pooling$nu
```

バランス診断（コホート別/プールそれぞれの不整合`q_sep`・`q_pool`など）は`$pooling`フィールドに保存されます。

Staggered SCM専用の推論関数として`scm_inference()`も用意されています。詳しくは[推論](#推論)の節を参照してください。

### プロットのカスタマイズ

`plot()`は以下の引数でスタイルを調整できます。

| 引数 | 説明 |
|:-----|:-----|
| `colors` | 系列（`treated`/`synthetic`/`donors`など）ごとの色を上書きする名前付きベクトル |
| `labels` | 凡例テキストを上書きする名前付きベクトル |
| `vline` / `hline` | 基準線の`geom_vline()`/`geom_hline()`スタイルを上書き。`FALSE`または`NULL`で非表示 |
| `vline_offset` | 処置開始線の位置（処置後1期目からの相対オフセット）。`-1`で処置前最終期に、`-0.5`のような小数も可 |
| `align` | `type = "trend"`/`"gap"`で、合成コントロールの水準を処置前ギャップ分シフトして処置ユニットと揃える |
| `show_donors` | `type = "trend"`で、ウェイト上位`show_donors`件のドナー系列を背景に薄く表示（`Inf`で全ドナー） |
| `fill` / `top_n` | `type = "weights"`の棒の色、および表示するドナー数の上限 |

```{r}
plot(fit_sdid, type = "trend", align = TRUE, show_donors = 10)
```

## 推論

各推定量に対応した推論関数が用意されています。

### どの推論を使うか

- SCM（Sharp）でドナー単位のプラセボ比較を行いたい：`mspe_ratio_pval()`
- SCMで処置ユニットが複数ある場合にランクに基づく置換検定を使いたい：`scm_rank_pval()`
- SCM（Staggered）でJackknifeまたはWild Bootstrap推論を使いたい：`scm_inference()`
- SDIDで標準的な推論（placebo / bootstrap / jackknife）を使いたい：`sdid_inference()`
- GSCで処置ユニットが少ない場合に、因子モデルの残差をリサンプリングする推論を使いたい：`gsc_boot()`
- GSC/SIで処置ユニットをリサンプリングする推論（処置ユニットが2つ以上必要）を使いたい：`gsc_inference()`, `si_inference()`
- `scm`/`sdid`/`gsc`/`mc`/`si`のシャープフィットで置換ベースの区間推論を使いたい：`conformal_inference()`

### SCM：プラセボテスト（`mspe_ratio_pval()`）

@abadie_synthetic_2010 / @abadie_using_2021 のMSPE比率に基づく置換検定です。各ドナーを処置ユニットとして扱ったプラセボSCMを推定します。Staggered SCMフィットには対応していません（後述の`scm_inference()`を使ってください）。

合成コントロール法の実行結果に対して、`mspe_ratio_pval()`を呼び出すと、プラセボ分布に基づくp値が返ります。

```{r}
inf_scm <- mspe_ratio_pval(fit_scm)
inf_scm$p_value
```

``` r
mspe_ratio_pval(
  fit,
  mspe_threshold = 0,     # プラセボに含める最小MSPE（デフォルト：0）
  max_iter       = 100L,
  tol            = 1e-4,
  use_covariates = NULL,  # NULL（デフォルト）は処置フィットの予測変数指定をプラセボにも適用
  alternative    = c("two.sided", "greater", "less"),
  mspe_prune     = Inf,   # 処置前MSPEが処置ユニットの何倍を超えるプラセボを除外するか
  statistic      = c("ratio", "post_mspe")
)
```

`mspe_prune`は、処置前のMSPEが処置ユニットの指定倍数を超えるプラセボを分布から除きます。@abadie_synthetic_2010 は20倍・5倍・2倍を用いています。`statistic`は順位をつける統計量で、`"ratio"`（デフォルト）は処置後/処置前のMSPE比、`"post_mspe"`は処置後MSPEそのもの（有限の`mspe_prune`と併用）です。

`use_covariates`は`NULL`がデフォルトです。`predictors`を指定したSCMフィットに対しては、各プラセボユニットも同じ予測変数指定で再推定されます（Abadie et al. 2010 / `Synth`の慣例：処置ユニットとプラセボの検定統計量を共通の仕様で計算）。outcomes-onlyのフィットでは高速なC++実装のプラセボループが使われ、挙動は変わりません。`TRUE`/`FALSE`で明示的にどちらかのパスを強制することもできますが、`FALSE`を共変量フィットに使うと、共変量ベースの処置統計量とoutcomes-onlyのプラセボ統計量を比較することになり、置換検定の交換可能性が崩れる点に注意してください。

プロットは以下のコマンドから実行できます。

```{r}
plot(inf_scm, type = "gaps")
```

- `loo_donors()`：重みのついたドナーを1つずつ除外するleave-one-out診断

```{r}
# 介入時点を処置前にずらしたプラセボ診断
pit <- placebo_in_time(fit_scm)
pit$placebo_att

# 寄与ドナーを1つずつ除外した頑健性確認

loo$att_range
```

### SCM（Staggered）：Jackknife・Wild Bootstrap推論（`scm_inference()`）

Staggered SCMフィット専用の推論関数で、@ben-michael_synthetic_2022 の2つの手法を提供します。`method = "jackknife"`（デフォルト）は付録A.1のleave-one-unit-outで、処置ユニットもドナーも1つずつ除外してウェイトを推定し直し、集計ATTを再計算します。`method = "wild_bootstrap"`は§5.3の重み付き乗数（wild）ブートストラップで、ウェイトは固定したまま各ユニットの寄与にゴールデン比の2値乗数（平均0・分散1）を掛けて再標本化します。再推定が不要なので、ユニット数が多いパネルではこちらが現実的です。Sharpフィットには使えません（`mspe_ratio_pval()`または`conformal_inference()`を使ってください）。

```{r}
inf_scm_s <- scm_inference(
  fit_scm_pooled,
  method = "wild_bootstrap",
  n_boot = 200,
  seed = 42
)
inf_scm_s$p_value
inf_scm_s$ci_lower
inf_scm_s$ci_upper
```

``` r
scm_inference(
  fit,
  method      = c("jackknife", "wild_bootstrap"),
  n_boot      = 1000L,
  level       = 0.95,
  alternative = c("two.sided", "greater", "less"),
  seed        = NULL
)
```

Partial Pooling（`nu`）・Fixed Effects（`fixedeff`）どちらのパスにも対応しており、コホート集計ウェイト（$N_{\text{treated}} \times T_{\text{post}}$）も考慮されます。処置ユニット数が少ないと推論の信頼性が下がるため、処置ユニットが3つ未満の場合は警告が出ます。

### SDID：`sdid_inference()`

@clarke_synthetic_2024 に基づく3種類の推論手法を提供します。

```{r}
# プラセボ検定（デフォルト）。SE・CIも自動で付与される
inf_sdid <- sdid_inference(fit_sdid, method = "placebo")
inf_sdid$p_value
inf_sdid$se
inf_sdid$ci_lower
inf_sdid$ci_upper
```

プラセボ検定では、処置ユニットを除いたうえで各ドナーを順に処置ユニットとみなし、ウェイトを含む推定量全体を再推定してプラセボ分布を作ります（処置ユニットが複数の場合は`n_boot`回のランダムな割り当て）。p値はプラセボ分布に基づく置換p値ですが、SEはプラセボ分布の分散 [@clarke_synthetic_2024 Algorithm 4]、CIはその正規近似です。処置ユニットのノイズがドナーと同程度であることを仮定しているため、ドナープールが小さい場合は解釈に注意してください。また、処置ユニット数よりドナー数が多い必要があります。

ブートストラップとジャックナイフは、処置ユニットも含めてユニットをリサンプリング（ジャックナイフは1ユニットずつ除外）するため、**処置ユニットが2つ以上**必要です（1つの場合はエラーになり、`method = "placebo"`を案内されます）。ここでは処置ユニットが2つあるStaggeredのフィット（`fit_sdid_s`）を使います。ブートストラップは処置・対照を区別せずパネル全体から復元抽出し、そのたびにウェイトも含めて推定し直します [@clarke_synthetic_2024 Algorithm 2]。

```{r}
# ブートストラップ（SE・CI付き）
inf_sdid_boot <- sdid_inference(
  fit_sdid_s,
  method = "bootstrap",
  n_boot = 200,
  seed = 42
)
inf_sdid_boot$se
inf_sdid_boot$ci_lower
inf_sdid_boot$ci_upper
```

``` r
sdid_inference(
  fit,
  method      = c("placebo", "bootstrap", "jackknife", "jackknife_global"),
  n_boot      = 200L,   # bootstrap のみ
  level       = 0.95,
  alternative = c("two.sided", "greater", "less"),
  seed        = NULL
)
```

### GSC：`gsc_boot()`

@xu_generalized_2017 のAlgorithm 2に基づく、推定された因子モデルの残差をリサンプリングするBootstrapです（処置効果のないパネルを推定値から作り直して再推定します）。残差は系列ごとリサンプリングして系列相関を保ち、対照ユニットには標本内残差、処置ユニットには対照ユニットを1つ処置ユニットとみなして除外した予測誤差を使います。リサンプリングできる処置ユニットが少ない場合に論文が推奨する方法で、処置ユニットが1つでも使えます。信頼区間は、推定値からBootstrap分布の分位点を引いて求めます。

```{r}
inf_gsc <- gsc_boot(fit_gsc, B = 499, seed = 42)
inf_gsc$p_value
inf_gsc$ci_lower
inf_gsc$ci_upper
```

``` r
gsc_boot(
  fit,
  B     = 499L,
  alpha = 0.05,
  seed  = NULL
)
```

### GSC：`gsc_inference()`

処置ユニットと対照ユニットを別々にリサンプリングして推定し直すBootstrap、または1ユニットずつ除外するJackknifeです。SharpフィットにもStaggeredフィットにも使えます。処置ユニットをリサンプリングするため、処置ユニットが2つ以上必要です（1つの場合は`gsc_boot()`か`conformal_inference()`を使ってください）。Staggeredフィットで`method = "jackknife"`を使うには、各コホートに処置ユニットが2つ以上必要です。`method = "jackknife_global"`は、パネル全体から1ユニットずつ除外してコホート間の共分散を保ちます。

``` r
gsc_inference(
  fit,
  method      = c("bootstrap", "jackknife", "jackknife_global"),
  n_boot      = 499L,
  level       = 0.95,
  alternative = c("two.sided", "greater", "less"),
  seed        = NULL
)
```

### SI：`si_inference()`

@agarwal_synthetic_interventions_2024 に対して、`gsc_inference()`と同じ方式のユニットのBootstrap / Jackknife推論を提供します。Staggeredフィットにも対応しています。処置ユニットも含めてリサンプリングするため、処置ユニットが2つ以上必要です（1つの場合はエラーになります）。ここでは処置ユニットが2つある`dat_s`で推定し直します。

```{r}
fit_si_s <- scm_fit(y ~ d | id + time, data = dat_s, method = "si")
inf_si <- si_inference(fit_si_s, method = "bootstrap", n_boot = 499, seed = 42)
inf_si$p_value
```

``` r
si_inference(
  fit,
  method      = c("bootstrap", "jackknife", "jackknife_global"),
  n_boot      = 499L,
  level       = 0.95,
  alternative = c("two.sided", "greater", "less"),
  seed        = NULL
)
```

### Conformal推論：`conformal_inference()`

@chernozhukov_exact_2021 の手法です。Moving-Block置換を用いた置換p値と信頼区間を返します。`scm`/`sdid`/`gsc`/`mc`/`si`の**シャープフィット**に対応しています。

```{r}
inf_conf <- conformal_inference(fit_scm, level = 0.95)
inf_conf$p_value
inf_conf$ci_lower
inf_conf$ci_upper
```

```{r}
# SDIDでも同様に使える
inf_conf_sdid <- conformal_inference(fit_sdid, level = 0.95)
inf_conf_sdid$p_value
```

``` r
conformal_inference(
  fit,
  tau0        = 0,    # 帰無仮説のATT（デフォルト：0）
  q           = 1,    # S_q統計量の指数（デフォルト：1）
  alternative = c("two.sided", "greater", "less"),
  ci          = TRUE,
  level       = 0.95,
  grid        = NULL,     # 候補値ベクトル（NULLの場合は自動設定）
  n_grid      = 200L,
  grid_mult   = 4
)
```

| 引数 | 説明 |
|:-----|:-----|
| `fit` | `scm_fit()`の結果（`scm`/`sdid`/`gsc`/`mc`/`si`、シャープフィット） |
| `tau0` | 報告するp値の帰無ATT（デフォルト：0） |
| `q` | $S_q = (T_{\text{post}}^{-1}\sum\lvert u_t\rvert^q)^{1/q}$ の指数。`alternative = "two.sided"`のときのみ使われ、片側検定では処置後残差の符号付き平均を使う |
| `alternative` | 対立仮説の方向 |
| `ci` | 信頼区間を構築するか（デフォルト：`TRUE`） |
| `level` | 信頼水準（デフォルト：0.95） |
| `grid` | 検定反転の候補$\tau_0$ベクトル。そのまま使われる。`NULL`の場合は推定値を中心に自動設定し、区間がグリッドの端に達する間は外側に広げる |
| `n_grid` | 初期グリッドの点数（デフォルト：200） |
| `grid_mult` | 初期グリッド半幅の乗数（処置前残差の標準偏差の何倍か。デフォルト：4） |
